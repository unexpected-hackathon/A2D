# seed-design (SEED Design 스니펫)

이 폴더의 파일은 [SEED Design](https://github.com/daangn/seed-design)(주식회사 당근마켓, Apache License 2.0)의 CLI(`npx @seed-design/cli add`)가 복사해 준 소스 코드다.

- 라이선스: [LICENSE](LICENSE) (Apache License 2.0), 귀속 고지: [NOTICE](NOTICE)
- 바꾼 점: 직접 고치지 않는다. 브랜드 색 변경은 `src/theme/brand.css`에서 토큰을 덮어써서 한다.
- 당근마켓의 브랜드 리소스(로고, 상호, 캐릭터 등)는 쓰지 않는다(NOTICE의 상표 안내).
- CLI로 다시 받으면 이 폴더의 파일이 덮어써질 수 있다. 린트 대상에서도 뺀다(`.oxlintrc.json`).
