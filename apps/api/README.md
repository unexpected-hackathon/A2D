# apps/api · A2D 백엔드

담당: 김성원(서비스·점검 엔진), 김강현(에이전트) · 커밋 scope: `api`, `agent`

## 역할

- 도메인 등록과 DNS TXT 소유권 확인 (FR-01). 확인 전에는 어떤 점검도 시작하지 않는다
- 자산 발견 5종(D-01~05)과 점검 항목(C-01~17 중 MVP)
- 위험 점수 계산과 오늘 할 일 3가지 선정
- Attack·Defense 에이전트: Python 함수 도구 호출, 가드 층, 리포트 생성
- 점검·점수·이력 API와 저장소, 감사 기록

점검 항목, 점수 공식, 도구 설계는 [docs/A2D_상세설계.md](../../docs/A2D_상세설계.md)를 따른다.

## LLM 호출

모델은 `model/`에서 띄운 vLLM의 OpenAI 호환 엔드포인트로 호출한다. 호출부는 한 곳에 모으고, 엔드포인트 주소는 환경 변수 하나로 바꿀 수 있게 둔다. 주소와 키는 `.env`에 두고 커밋하지 않는다.

## 기술 스택

언어는 Python. 웹 프레임워크와 DB는 정해지면 여기에 적는다.
