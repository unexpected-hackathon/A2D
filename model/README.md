# model · AI 모델 배포 스크립트

담당: 김성원 · 커밋 scope: `model`

Attack·Defense 에이전트가 쓰는 LLM을 GPU 서버에 띄우는 스크립트를 둔다.

| 항목 | 값 |
| --- | --- |
| 모델 | Qwen3-8B (BF16, Apache 2.0) |
| 서빙 | vLLM, OpenAI 호환 엔드포인트, 도구 호출 사용 |
| 서버 | NVIDIA L4 (23GB) |
| 문맥 길이 | 8천~1만 6천 토큰 (메모리에 맞춰 조정) |

## 들어갈 스크립트

- 서버 환경 준비 스크립트 (드라이버·Python 환경 확인, vLLM 설치)
- 모델 내려받기 스크립트
- vLLM 서버 실행 스크립트와 설정값
- 엔드포인트가 응답하는지 확인하는 점검 스크립트

## 주의사항

- 모델 가중치는 커밋하지 않는다(`.gitignore`에서 제외됨). 스크립트로 내려받는다.
- 서버 주소, 계정, VPN 정보는 커밋하지 않는다. `.env.example`에 키 이름만 적는다.
- vLLM과 모델 버전을 고정하고, 바꾸면 README의 외부 자원 표도 고친다.

## 실행

스크립트가 생기면 순서대로 적는다.
