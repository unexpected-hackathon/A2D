## 쓸 때 지킬 것

- 투명 배경 로고(a2d-logo.png, a2d-logo.svg)는 밝은 바탕에만 쓴다. 선 가운데가 남색이라 어두운 바탕에서는 보이지 않는다. 어두운 바탕에는 a2d-logo-dark.png나 아이콘을 쓴다.
- A와 선이 겹치는 곳의 틈은 실제로 비어 있어(마스크) 어떤 밝은 바탕에 올려도 틈이 보이지 않는다.
- 늘이거나 눌러 비율을 바꾸지 않는다.
- PNG를 다시 만들 때는 SVG를 고친 뒤 같은 방식으로 내보낸다(resvg로 렌더링).
