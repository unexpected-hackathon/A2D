## 1. 비침습 점검 항목

### 1.1 비침습 점검이란

일반 방문자가 할 수 있는 방법으로, 누구나 볼 수 있는 것을 **읽기만 해서** 위험을 찾는 점검입니다.

- 소유권을 증명한 도메인만 점검
- 외부 주소(클라우드 저장소·백엔드 대행 서비스 등)는 **우리 사이트나 DNS가 직접 가리키는 것만** 점검하고, 이름을 추측하지 않음
- 읽기 요청(HTTP GET·HEAD)과 DNS·공개 등록 정보 조회만 사용. 쓰기·변경·삭제 요청은 보내지 않음
- 호스트별 요청 속도와 점검당 총 요청 수를 제한
- 응답 속 개인정보·비밀키는 가린 발췌만 근거로 저장

### 1.2 구분

- **1차**: 먼저 구현. 위험 점수에 반영
- **1차·식별**: 1차에서 정보만 표시. 위험 점수 미반영
- **2차**: 이후 단계로 미룸
- **(승격)**: 처음 검토에서 2차였다가 1차로 변경 · **(신설)**: 검토 중 새로 추가
- "조회"는 HTTP 읽기 요청(GET·HEAD) 1회입니다. 셀 안의<br>**조건**·**2차 사유** 등은 검토에서 정한 내용입니다.

### 1.3 A. 자산 찾기 — 무엇이 인터넷에 나와 있나

|---|---|---|---|---|---|
| 1 | **하위 도메인 찾기** | 자주 쓰는 이름(`dev`, `admin`, `api`, `staging` …)을 붙여 존재하는 하위 도메인 확인 | DNS 조회 (단어 수만큼) | 잊힌 서버가 가장 흔한 침입 경로 | 1차 |

| 3 | **robots.txt · 사이트맵** | 검색 엔진용 안내문에 적힌 "검색 금지" 경로와 사이트맵 주소 수집 | 조회 2회 | 숨기고 싶은 경로 목록이 오히려 공개됨 | 1차 |
| 4 | **위탁 서비스 연결** | 외부 업체(쇼핑몰·예약·결제 등)로 연결된 주소(CNAME) 식별 | DNS 조회 | 외부 업체 쪽 사고가 우리 사고가 됨 | 1차 |
| 5 | **인증서 발급 기록 조회 (승격)** | 공개 인증서 발급 기록(CT 로그)에서 우리 도메인 이름 전부 찾기. 대상 서버에는 요청하지 않음<br>**조건** crt.sh 조회, 실패 시 다른 검색 서비스(Certspotter 등)로 대체 · 찾은 이름은 #1과 같은 확인 과정을 거침 · 데모는 샌드박스에 가짜 장부 | 외부 공개 DB 조회 | 사전 대입으로 못 찾는 하위 도메인 발견 | 1차 |

| 7 | **열린 포트 확인** | DB·원격 접속 등 주요 포트가 인터넷에 열려 있는지 (연결만 하고 데이터는 보내지 않음)<br>**2차 사유** 도메인이 내 것이어도 IP는 공용 호스팅·CDN 소유일 수 있어 소유권 원칙이 깨질 수 있음 · 대안으로 Shodan 등 기존 스캔 DB 활용 검토 | TCP 연결 시도 | 데이터베이스 직접 노출은 대형 유출 원인 | 2차 |

## 2. 위험 점수

1부의 각 점검 결과(발견)에 위험 점수를 매기고, 이를 모아 조직 전체의 안전 점수와 등급을 냅니다. 점수는 AI가 아니라 정해진 계산식으로만 냅니다. 같은 결과에는 언제나 같은 점수가 나오고, 계산 과정을 그대로 보여 줄 수 있습니다.

### 2.1 점수 체계

| 항목 | 결정 |
|---|---|
| 발견 점수 | 4요소(노출도 E · 악용 용이성 X · 데이터 민감도 D · 자산 중요도 C, 각 1~5) |
| 계산식 | 위험 점수 = 100 × ((E × X × D × C)^(1/4) − 1) / 4 × 신뢰도 계수 |
| 신뢰도 계수 | 확인됨 1.0 · 가능성 0.8 · 확인 필요 0.6 |
| 반올림 | 발견 점수·조직 위험 점수·안전 점수는 계산 끝에 한 번만 소수점 첫째 자리에서 반올림. 등급 판정은 반올림한 값으로 |
| 발견 등급 | 80 이상 긴급 · 60 이상 높음 · 40 이상 중간 · 그 외 낮음 |
| 조직 점수 | 0.7 × 최고 발견 점수 + 0.3 × (그다음 상위 5개 합 ÷ 5) — 발견이 5개보다 적으면 빈자리는 0 |
| 보여 주는 방식 | 안전 점수 = 100 − 조직 위험 점수 · A 90+ / B 72+ / C 58+ / D 44+ / F 그 미만 |
| 등급의 의미 | 가장 심각한 문제의 등급보다 좋게 나오지 않음. 문제가 여러 개 쌓이면 더 내려갈 수 있음 |
